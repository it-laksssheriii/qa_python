# Тесты для BooksCollector

Это моя первая учебная работа по юнит тестированию. Я только начинаю учиться, поэтому в проекте я пишу тесты на pytest для готового класса 'BooksCollector'.

# О чём приложение

'BooksCollector' — небольшая программа, с помощью которой можно:

- добавлять книги;
- задавать каждой книге жанр;
- получать список книг для детей;
- вести список избранных книг.

Внутри класс хранит:

- 'books_genre' — словарь «название книги → жанр»;
- 'favorites' — список избранных книг;
- 'genre' — доступные жанры: Фантастика, Ужасы, Детективы, Мультфильмы, Комедии;
- 'genre_age_rating' — жанры с возрастным рейтингом: Ужасы, Детективы.

Правила работы, которые я проверяю тестами:

- название книги должно быть от 1 до 40 символов;
- одну книгу нельзя добавить дважды;
- жанр можно задать только книге из коллекции и только из списка доступных жанров;
- книги жанров «Ужасы» и «Детективы» не попадают в список книг для детей;
- в избранное можно добавить только книгу из коллекции и только один раз.

# Как запустить тесты

1. Установить pytest:

   pip install pytest

2. Запустить тесты из папки проекта:

   pytest tests.py -v

В результате pytest покажет список запусков. 'PASSED' означает, что тест прошёл, 'FAILED' — что результат не совпал с ожидаемым.

# Что я проверяю

В tests.py один класс 'TestBooksCollector' и 10 тестовых функций. Из-за параметризации pytest запускает их 18 раз.

Метод | Что проверяю 
'add_new_book' - добавление книг; граничные длины названия (1 и 40 символов добавляются, 0 и 41 — нет); у новой книги нет жанра 
'set_book_genre' - установка каждого из 5 доступных жанров
'get_book_genre' - получение жанра по названию книги
'get_books_with_specific_genre' - возвращаются только книги нужного жанра
'get_books_genre' - возвращается словарь книг (он используется в проверках добавления книг)
'get_books_for_children' - книг жанров «Ужасы» и «Детективы» нет в списке для детей
'add_book_in_favorites' - добавление книги в избранное
'delete_book_from_favorites' - удаление книги из избранного
'get_list_of_favorites_books' - получение списка избранных книг

Тесты покрывают основные сценарии каждого метода, но не все возможные случаи.
